# 플레이어 가이드

수정일: 2026-10-15  
상태: `PlayerCtrl`, 작물 컨트롤러 정적 코드 확인 · 플레이 테스트 전

이 문서는 현재 게임 코드에서 확인한 플레이어 입력과 작물 상호작용을 설명한다. 수치와 동작은 코드 설정 기준이며 실제 플레이 감각이나 밸런스를 검증한 결과는 아니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| `Left Shift` | 달리기 |
| 마우스 이동 | 시점 회전 |
| 마우스 왼쪽 버튼 누르기 | 2m 안의 조준 대상에 상호작용. 작물 작업 중에는 누른 상태를 유지한다. |
| `Tab` | 안내 창 열기/닫기. 창을 열면 경기 시간이 멈춘다. |
| `1` | 보유 중인 Pickup Truck 사용 |
| `2` | 보유 중인 Boost Drone 사용 |
| `3` | 보유 중인 Toxic Drone 사용 |

작물에 가까이 가서 화면 중앙으로 조준하면 대상 윤곽선이 표시된다. 작물 작업 중에는 이동이 제한된다. 다른 작물이나 빈 공간을 조준하거나 버튼을 놓으면 작업이 취소되거나 물주기가 중단될 수 있다.

## 내 밭 관리

빈 밭을 조준한 채 왼쪽 버튼을 약 4초간 누르면 심는다. 물주기는 작물 조준 후 버튼을 계속 누르고 있으면 시작된다. 코드상 물뿌리개 작업은 물주기를 시작한 다음 약 10초 대기하는 흐름이며, 중간에 버튼을 놓으면 작업이 취소되고 작물의 `isWatering` 상태도 해제된다. 성장 단계는 물을 주는 동안 기본 2초 간격으로 진행한다.

최대 성장 단계에 도달하면 익는 중 표시가 나오며, 기본 10초 뒤 수확 가능 표시로 전환된다. 익은 내 작물을 약 4초간 계속 조준·상호작용하면 수확하고 6점을 얻는다. 수확한 밭은 빈 상태로 돌아와 다시 심을 수 있다.

## 상대 밭

상대 밭에서 조작할 수 있는 것은 코드상 익은 작물 수확이다. 상대의 익은 토마토를 2m 안에서 조준하고 왼쪽 버튼을 약 4초간 누르면 수확하며 4점을 얻는다. 상대 농장에 씨앗을 심거나 물을 줄 수는 없다. AI가 사용 중인 작물은 수확할 수 없다.

## 점수와 아이템 획득

- 내 작물 수확: 6점.
- 상대 작물 수확: 4점.
- 내 작물 수확 시 0~2의 무작위 결과에 따라 Pickup Truck 또는 Drone 아이템을 받을 수 있다. 이미 같은 종류를 보유 중이면 다시 보유 상태를 부여하지 않는다. 무작위 결과 중에는 아이템을 주지 않는 경우도 있다.
- 상대 작물 수확 점수는 오르지만, 아이템 보상 코드는 내 작물 수확 처리에 연결되어 있다.

아이템을 보유하면 화면의 해당 아이콘이 켜진다. 드론 아이콘은 Boost와 Toxic 선택지를 함께 표시한다. 아이템별 자세한 대상과 현재 코드상 주의점은 [아이템 사용 안내](items-guide.md)를 참고한다.

## 안내 창과 경기

`Tab`으로 안내 창을 열면 `Time.timeScale`이 0이 되어 경기가 멈추며, 닫으면 다시 진행된다. 경기는 300초이며 종료 시 Player와 AI 점수에 따라 승리·패배·무승부 씬으로 이동한다. 씬 흐름은 [게임플레이 흐름](../architecture/gameplay-flow.md)에 정리되어 있다.

## 소스 기준

입력·상호작용은 `Assets/02.Scripts/Player/PlayerCtrl.cs`, 점수와 성장 보상은 `Assets/02.Scripts/Player/PlayerTomatoCtrl.cs`, 경기 시간과 점수 처리는 `Assets/02.Scripts/Managers/GameManager.cs`를 기준으로 정리했다. 이 안내는 Editor에서 직접 플레이해 검증한 매뉴얼이 아니다.
