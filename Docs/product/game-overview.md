# 게임 개요

## 게임 정체성

`LEAVE ME ALONE`은 토마토 농장을 운영해 상대보다 많은 점수를 얻는 경쟁 게임이다. 저장소 설명은 Dedicated Server 멀티플레이어 버전을 지향한다고 밝힌다. 현재 경기 코드는 Player와 AI 농부가 각각 농장을 관리하는 구조다. 온라인 대전이 가능한 상태라는 의미는 아니다. 구현 흐름은 [게임플레이 흐름](../architecture/gameplay-flow.md), 저장소 기준과 네트워크 관련 범위는 [Docs 목차](../README.md#현재-기준)를 참고한다.

## 경기 흐름

현재 `GameManager`는 300초 경기를 운용한다. 경기 시작 씬에서 안내를 넘긴 뒤 `MainGameScene`으로 이동한다. 시간이 끝나면 Player와 Enemy 점수를 비교해 승리·패배·무승부 씬 중 하나를 연다.

토마토는 밭의 빈 상태에서 심고, 물을 주어 성장시킨 뒤 익었을 때 수확한다. Player 조작 코드에서 심기와 수확 상호작용은 각각 4초 대기를 사용한다. 양쪽 작물 컨트롤러는 물을 주는 동안 기본 2초 간격으로 성장 단계를 진행하며, 마지막 성장 단계에 도달하면 기본 10초 후 익은 상태로 바뀐다. 세부 프리팹 단계와 씬 설정은 해당 컨트롤러와 MainGameScene을 기준으로 한다.

## 아이템

Player 작물 수확 시 일정 확률로 차량 또는 드론 보유 상태를 받을 수 있다. 드론 보유 상태에서는 사용할 드론을 선택한다.

| 입력 | 동작 | 코드에서 확인한 효과 |
| --- | --- | --- |
| `1` | Pickup Truck | 차량을 생성해 상대 농장 쪽으로 이동하며 작물을 훼손한다. 상대 차량 아이템이 사용 중이면 생성 입력이 막힌다. |
| `2` | Boost Drone | 자기 농장의 성장 간격을 1초, 익는 시간을 5초로 낮춘다. 기본값 복구 예약은 60초다. |
| `3` | Toxic Drone | 현재 Player 독 드론은 `GameManager.playerTomatoes`, Enemy 독 드론은 `GameManager.enemyTomatoes`를 초기화한다. 즉 코드상 각 소유자의 농장 배열을 대상으로 한다. 상대 농장을 겨냥한다는 제품 설명과 일치하는지 확인이 필요하다. |

Enemy의 아이템 사용 조건과 생성 경로는 `Assets/02.Scripts/Enemy/EnemyCtrl.cs` 및 Behavior Graph 액션을 따른다. Player와 Enemy가 같은 입력·보유 정책을 사용한다고 가정하지 않는다.

## 구현 범위 구분

- **현재 코드에서 확인:** 로컬 Player 입력, Behavior Graph를 사용하는 Enemy, 작물 성장·수확, 차량과 드론 효과, 5분 점수 경기.
- **프로젝트 방향:** Dedicated Server 멀티플레이어.
- **이 문서에서 완료로 주장하지 않는 항목:** 클라이언트 간 경기 연결, 서버 권한 판정, 네트워크 작물 상태 동기화, 온라인 세션·매치메이킹. 네트워크 패키지 설치만으로 이 기능을 확인할 수 없다.

경기 승리 조건, 점수 정책, 아이템 확률을 조정할 때는 코드의 상수와 씬·Behavior Graph 설정을 함께 확인한다. 이 문서는 해당 값을 제품 밸런스로 확정하지 않는다.
